- TechBehemoths menampilkan Media Digitech Indonesia di Yogyakarta sebagai perusahaan custom web design/development dan menyediakan tautan website `https://mediatechindo.com`; halaman resminya menyebut pengembangan software yang dapat disesuaikan dengan lingkungan kerja dan menyediakan menu Hubungi Kami.

Catatan: direktori publik dapat memuat listing bersponsor atau deskripsi yang berubah. Informasi tersebut hanya dipakai untuk menemukan kandidat, bukan sebagai endorsement.

## Pemeriksaan keterjangkauan URL

Pemeriksaan HTTP awal menunjukkan sebagian besar website kandidat dapat dijangkau. `lumenteknoindo.co.id` mengembalikan HTTP 500, `byteik.com/en` belum memberikan respons dalam pemeriksaan awal, dan `bocistudio.com` mengalami timeout. Kandidat tersebut tetap disimpan sebagai prospek dengan catatan bahwa kanal kontak harus diverifikasi manual sebelum outreach. `kulkul.tech` mengembalikan redirect yang normal. Status HTTP bukan penilaian kualitas bisnis.
